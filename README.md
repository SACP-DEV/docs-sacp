# 📚 SACP - Documentación Técnica

Repositorio oficial de documentación del **Sistema de Control de Parqueo (SACP)**.

## 📋 Descripción

Este repositorio contiene toda la documentación técnica del sistema SACP, diseñada para explicar a clientes y desarrolladores el funcionamiento de cada componente del sistema.

## 🏗️ Arquitectura del Sistema

El sistema SACP está compuesto por 3 repositorios:

| Repositorio | Tecnología | Propósito |
|-------------|------------|-----------|
| [api-sacp](https://github.com/rlarquing/api-sacp) | NestJS + MongoDB | API RESTful Backend |
| [web-sacp](https://github.com/rlarquing/web-sacp) | Next.js + React | Panel de Administración Web |
| [apk-sacp](https://github.com/rlarquing/apk-sacp) | Expo + React Native | Aplicación Móvil (APK) |
